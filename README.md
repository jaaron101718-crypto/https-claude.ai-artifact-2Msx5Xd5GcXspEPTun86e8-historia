# GoalProject · app instalable

Versión instalable (PWA) de la app de GoalProject: análisis táctico, microciclo y pizarra para entrenadores.

Para instalarla en el móvil, abre la dirección de GitHub Pages en Safari (iPhone) o Chrome (Android) y elige «Añadir a pantalla de inicio».

- Los datos (cuentas, pizarras, análisis) se guardan en cada dispositivo.
- El foro solo está disponible en la versión de la app dentro de claude.ai.
- Funciona sin conexión una vez abierta por primera vez.
